# 妖怪ウォッチ2 Engine V3-5-6｜学校の通常レンタル戦：テンポ監査とFriend画面整理（2026-10-31 JST）

## 工程の意図・結論

**8つの通常学校6vs6試合を、実Host MatchProtocolに同じ学校Friends戦闘オプションを使い、正規`advanceAuto()`のみで240行動まで監査した**。試合が長くなり得る事実を確認したが、今回の入力なしのケースでは自動進行停止や連続HP無変化による固着は見つからなかった。したがって**2600ms間隔、攻撃力、技威力、性格・AIを独断変更しない**。

学校友達向けの見た目で、完成作品に不要な研究文言と通信番号が残っている問題を確認し、**友達対戦UIからのみ研究ラベルを外す**。ステータス、妖気、HP、ウォッチ、操作、アニメーションとHost権限は変更しない。研究用画面では残して比較できる。

**V3-5-6のPCで可能な工程は実装・検証、学校Safari 2台と本人提供元MP4の直接視覚照合は未検証**。V3-5の「学校実機で原作に似たゲーム体験が得られるか」は未完了。

## 実装（V3-5-6）

1. `ui/match-stage.mjs`：`showResearchLabels=true`を研究UIのデフォルトのまま追加。学校Friendsは`showResearchLabels:false`にし、画面上の「再現研究中」の注意帯、`REV / A / B`内部通信番号、英語開発タグを隠す。タッチ入力進捗に出ていた「試験用の入力条件」を学校版では消す。**ID/内部状態は保持**するため既存のACK/正規Hostスナップショットはそのまま。
2. `lab/sites-embed-online-entry.mjs`：Friendsの時だけ`showResearchLabels:false`を指定。研究用/非Friendsでは以前の表示を維持。
3. `tools/build-sites-online.mjs`：Friends側の埋込画面上部を「輪戦｜友達対戦」と簡潔な**ホスト画面を開いたままにする**案内に変更。ローカル研究用/それ以外の構成は元の研究ラベルを維持。なお発生確率の低い通信再設計、匿名認証の追加、Rules変更は一切行っていない。
4. `tools/sites-online-smoke.mjs`：本物のFirebase RTDB emulator/2つのChromium srcdocで、**友達対戦から研究ラベルを隠しつつ、必要なわざ/おはらいボタンは表示され、タッチバーには開発文言が残らない**ことを判定。通常の必殺、G、負のとりつき後のおはらい、六体KOまでの旧実通信E2Eも維持。
