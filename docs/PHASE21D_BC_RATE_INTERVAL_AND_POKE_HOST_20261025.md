## 2. 実装A：24観測からの一定レートの厳密区間
既存 `engine/phase21d-soul-rate-evidence.mjs` を**拡張**（別のSoulエンジンを作らない）：
- `constantRecoveryInterval(capacity,turnsToFull)`：空ゲージCが1行動につき一定量rずつ増え、初めて満タンになるのがT回目なら、数学上
```
C/T <= r < C/(T-1)  (T >= 2)
```
- `compareSameCapacityRateIntervals()`：同じ容量・同じ隣接魂数の記録を、**端点を有理数のまま**交差判定。丸め候補式`floor(5+N*C/50)`を一切使わず、複数の観測が単一の一定レートで両立できるか確かめる。
- 容量130の原典二群は、魂0個の場合26/26行動、1個なら19/19行動で整合。**2個の場合13/14行動となり交差区間が空**：
  - 13行動で初満タンなら r >= 130/13 = 10
  - 14行動で初満タンなら r < 130/13 = 10
  - 同じ条件・同じ一定rがこの2つを同時には満たせない。
- **結論は原作内部の例外確定ではない。** 測定の開始ゲージ・妖気補正スキル・装備レベル・ターン解釈・一時的な行動停止・ゲージの可視丸めや原文記載誤差など、どの違いがあったかは未検証。すべて同条件だったという前提自体を改めて調べる必要がある。
- `tests/phase21d-soul-rate-evidence.test.mjs`へ3件：厳密な上下限、13/14の不両立、T=1と入力範囲・原作フレーム規則への誤昇格防止。従前の24元データ・23/24一致・唯一の差は**そのまま保持**。
