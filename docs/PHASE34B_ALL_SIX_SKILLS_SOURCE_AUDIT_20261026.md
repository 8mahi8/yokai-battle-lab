## 実装と既存研究への差分
- `engine/skill-effects.mjs`: 3種類追加 `critImmune`, `lastStand`, `guardBreak`。HP1耐久は **対象現在HP=1でも使える**（初回の致死攻撃を1ダメージだけ無効にする）。2回目以降は通常のダメージを受ける。副作用のない `resolveLastStand` は実被害量を返す。
- `engine/combat.mjs`: 6体のオリジナルレンタルすべてに別種の原作由来スキルを付与。既存のホスト側シードで運用。
  - `applyDirectDamage`: 通常攻撃・単体/全体必殺・零式つつくの直接ダメージ経路で共通使用。発動済みの状態 `spentLastStand` はホストのスナップショットにも保持。HP1耐久時、KO/行動不可/勝敗/攻撃側撃破数を誤計上しない。
  - クリティカル免疫は既存の `yw2CriticalProbability` へ、ガードくずしは既存の `calculateOneHit` へ反映。妖術を貫通させない。
  - `careAtActionBoundary`：『2』の「1ターン終了毎」に合わせて**自分も相手も1行動が終わるたび**に、両チームで隣の生存者を回復。現行の回復2%はあくまで試遊用。
  - 以前の `careOnOwnerTurn` 純関数は同一受け手1名分の計算補助として保持。実戦トリガーとしては利用しない。
  - `enableRentalSkills` は既存のtrue/false比較に対応。通常の友達用playtest設定は有効。古い研究テストは設定しなければ無効のまま。
- `ui/match-stage.mjs`: 自分の選択キャラに6種のスキル名を表示し、既存のイベント一覧に自動発動を表示。スキル発動というだけで演出中の相手表示を固定する**未証明の処理は追加しない**。
- `tests/phase34b-remaining-original-passive-skills.test.mjs` を新設し、6体の装備、HP1一度耐久とKO不発、実必殺からの2回命中、実物理攻撃のクリティカル無効、ガード貫通、決定的対戦ジャーナル、各行動時の隣接回復とKO除外を検査。
- 引き続き前段の `tests/phase34-original-passive-skills.test.mjs` を走らせる。
