## 原作研究の根拠と限界
1. [RC「妖怪ウォッチ2実験結果まとめ」えんら魂/隣接妖怪妖気回復魂について](https://note.com/ricosama0726/n/n14710bbe446c) — 実機を使ったプレイヤー実験でグレード・威力/妖気型別に最大ゲージ量、隣接えんら魂0/1/2つを置いた満タンまでの行動数を報告。本文によれば「攻撃しなければ本人の行動後+5」、攻撃した場合の増加量は別途実験予定。**オリジナル3DSのゲームコードそのものは未検証**。行動1回と絶対時間・他妖怪の手番を同一視しない。
2. [たくトンボ 対戦基礎の妖気仕様](https://note.com/tombow_yw/n/n1e4cf179d2d9) — 技MAX前提で自然なチャージ速度をおおむね6グループと記述。えんら魂が通常の遅い妖怪のチャージを速める。正確な個別回復数・フレームは提示せず、知識として補助。
3. [ゲームエイト 妖気のため方](https://game8.jp/youkai-watch2/504498) — 自然回復・隣接魂などの存在を解説。これだけでは行動後なのか常時時間依存かを厳密に確定できない。
4. [零式とつつく](https://gamepedia.jp/youkai-yw2/archives/1873) — つつくの成功で妖気吸収が起こり得る。**確率・recipient・amount・タイミングは未確認**。
5. [対戦競技者ケイゾウのトホホギス運用](https://note.com/brainy_mimosa371/n/nbe2ef67680bd) — 妖気吸収→必殺→つつく→必殺の反復戦術の存在を定性的に報告。これは**ループがゲーム上成立する観測**であって、個別妖気数値を保証しない。初期レンタル6体への別キャラ導入はしない。
6. [妖怪ウォッチ2 通信対戦の零式のつつく効果](https://asobigokoro.work/yokai-watch-2-ganso-honke-shinuchi/) — 通信対戦でのつつくは通常ダメージ、妖気吸収、999固定ダメージの3種と説明（攻略記事の二次情報、確率は不明）。PvEのお金・友達率を対人に持ち込まない。

## 今回実装した研究比較器
`engine/phase21d-soul-rate-evidence.mjs` に上表のデータを**ソース実測値として明示したまま固定**し、候補式
```text
H = 報告されたゲージ上限、N = 隣接回復魂の個数（0..2）
1行動分の仮回復量 = floor(5 + N × H / 50)
満タンまでの仮行動数 = ceil(H / 1行動分の仮回復量)
```
を独立に計算、`comparePublishedRechargeEvidence()`で24件を総当たり検証。

**23/24件が一致・1/24件は不一致。**
- **違反する唯一の観測:** Grade2威力型（上限130、魂2個）。実測報告**14行動**、候補式は**13行動**。
- 一方同じ上限130のGrade3妖気型は魂2個で13行動。**容量のみで全結果を決められるとは証明できない。**
- 回復量の端数処理、内部の固定小数点、実験条件、技の個別例外などの原因は不明。**式を原作確定扱いしない**。
- 実測表の8行はRC観測のまま保存。式に合わせて観測14を13へ「修正」しない。
- `predictResearchRecharge`のレスポンスは`originalParityVerified:false`。正規ホスト・Firebase・レンタルキャラの上限値と既定ルールは一切変更していない。

`tests/phase21d-soul-rate-evidence.test.mjs` に追加した7テスト：

3. 同じ上限130で二例の差があることを維持
4. 計算結果を仮説と明示
5. 上限・丸め境界ケース
6. 不正値を拒否
7. 本番相当ホストのデフォルトに隣接魂研究が漏れず、guard+5とjournal replayが壊れない
