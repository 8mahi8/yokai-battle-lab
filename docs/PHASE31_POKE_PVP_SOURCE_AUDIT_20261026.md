# Phase31｜零式つつく・原作通信対戦の効果分類を先に調べて実装（2026-10-26）

## 本人の厳密な方針
必ず原作資料を調査し、分かった種類・対象条件・複合効果はそのまま採用。**調べても分からない量や発動率だけを試遊用仮値として扱う**。完全な原作キャラの外見再現は不要。Google Sites公開版/学校の固定Phase27/main/Supabase認証・DBには触れず、本人が「Googleサイトに貼るやつちょうだい」と依頼した時だけ渡す。

## 効果の種類と根拠の強さ
- [Nintendo公式 妖怪ウォッチ2英語版電子説明書](https://csassets.nintendo.com/noaext/image/private/t_KA_PDF/manual-3DS-Yo-Kai_Watch_2_Fleshy_Souls?_a=DATAg1AAZAA0) Model Zero Command Poke：サボり/とりつき状態の敵をつつき、妖気メーター吸収/お金/仲間確率などが起こる。**公式説明書は通信対戦限定の999ダメージと発生率を述べていない**。
- [原作公式ゲーム紹介](https://www.youkai-watch.jp/yw2/game/game06.html)：隠れたツボを探してつつく。お金/友達になる確率のストーリー効果を確認。
- [妖怪ウォッチ2 Wikipedia系ゲームシステム解説](https://ja.wikid.org/妖怪ウォッチ2_元祖/本家/真打) と [他の解説](https://asobigokoro.work/yokai-watch-2-ganso-honke-shinuchi/)：一般のつつくには5種（ダメージ・妖気吸収・999ダメージ・お金・仲間確率）、**通信対戦には先頭3種**と記載。**これは公式ではなく二次情報。実機と照合済みだとは主張しない**。
- [2015年のプレイヤー質問・回答](https://youkai-gh.g-takumi.com/bbs_detail.php?bbs_id=29926)：サボり/とりつき時に1体につき1回、ダメージ/妖気吸収/お金/仲間の経験則。
- **証拠ありのカテゴリ**：PVP用のHPダメージ・妖気吸収・999ダメージ。**PVP用にお金/仲間効果を勝手に追加しない**。
- **未確認**：3種類の厳密な確率、通常ダメージ量・計算式、妖気吸収量・味方受取先、プレイヤーがツボを制御できる割合や999出現率。これらは別途実機照合が必要。

## 今回のゲーム実装（正規ホストだけ決定）
- engine/playtest-soul-tuning.mjs：仮値を一元追加。ダメージ35、妖気移動上限35、999ダメージ、**結果配分：通常ダメージ49％・妖気吸収50％・999ダメージ1％（全部試遊用仮値）**。ソースに書かれていない数値は、原作確定値と混ぜない。
- engine/combat.mjs：今までの「必ず妖気吸収」から、ホストのシード付き乱数で**PVP資料にある3種類だけ**を選ぶ。HPダメージ・一撃時には既存のチャージ中断・KO・行動不能・勝敗判定を利用。999は技表示上の値で、HP225の敵なら実際に減るのは225。対象は1回のつつきのみ。
- 妖気吸収は旧Phase26の仕様を保持（敵の実妖気から最大35・最初の味方生存前衛へ、空ゲージなら0）。**受取先は原作未確認の仮仕様**。
- ui/battle-vfx.mjs と ui/match-stage.mjs：戦況欄・効果表示が3結果を区別し、HPダメージのみ被ダメージ演出。クライアントは結果・確率を選べない。研究用/非playtestの挙動はそのまま。新規通信路・新DB・再読込対戦復帰はなし。
