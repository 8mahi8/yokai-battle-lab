# Phase30-B｜妖怪ウォッチ2の「復活＋全体回復」を原作資料で再調査し修正（2026-10-26）

## ユーザー指摘と結論
本人より「1人だけ復活ではなく、全体回復＋気絶から復活では？」と指摘。
**指摘の本質は正しい**。原作の代表的な復活系必殺「満開サクラサク」「ポカポカばーちゃん」は、**味方全体のHP回復と気絶からの復活を組み合わせる**技。2026-10-26に再調査した。

ただし**例外として単体だけの復活技も存在**する。おでんじん「命のアツアツおでん」は『妖怪ウォッチ2』の複数の独立資料で「味方1体を復活」と明記されている。単体復活という技カテゴリ自体は削除しない。

前回のPhase30が見落としていたのは、**よく使われる全体型の「復活＋HP回復」を実装せず、ほたるに単体復活だけを割り当てた点**。今回修正する。

## 今回の実装範囲・数値の注意
- 既存の **engine/special-effects.mjs** に kind=revive-heal、scope=team を追加。『味方全体』は今回の簡易版では**6体（控え含む）**と解釈し、同じ必殺の中で
  - 生存メンバー：HPを最大値まで超えない範囲で回復
  - 気絶メンバー：回復したHPで復活
  - 6体全員の処理はそれぞれ**一回だけ**、敵側には波及させない。
- **engine/combat.mjs** の既存戦闘エンジンから、ほたるA5/B5の必殺だけ revive-heal に変更。必殺実行時は味方6体を渡し、既存の syncCanAct を介して気絶者の行動許可を回復。G技の効果も既存の倍率計算を利用。
- **単体復活 kind=revive、scope=one はそのまま残す**。おでんじんのような技のカテゴリとして使用できるが、今回の初期レンタルに当てる必要はない。
- HP回復量 **85** とG時の倍率は原作の正確な数値ではなく、本人の希望による試遊用仮値。**前衛/控えのどこまで即時回復するか、復活HP量の厳密な内部規則はこの資料だけでは原作完全一致を保証できない**。分類と大枠を先に揃えた。
