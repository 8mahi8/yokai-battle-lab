# G1 静止モデル・シート審査記録（2026-10-22）

## 作業結果
- 既存V0.1とは別に、正面・斜め前・背面が一つの画像で確認できる**新しい静止造形候補**を制作。
- 方向別に切り出した静止画と、80 / 140 / 220pxの実ゲーム近似サイズ比較シートを作成。
- 体の構成を研究するため、SVGの**正面ベクトル原画試作**もローカルに制作し、PNGレンダリングを目視確認。
- **どちらも未承認（G1候補）。まだアニメーション・リグ・プレイ可能なキャラではない。** 勝手にmainへマージしない。

## V0.1からの改善点（観察）
- 白い額の特徴的な模様、黒く大きい瞳＋黄色い輪、片耳の欠けを明瞭にした。
- マズル・鈴・白い胸と腹巻の距離関係を分離。前回の一般的な猫の顔から方向転換。
- 顔の横に浮いた炎ではなく、胴体背面に接続する二本の尾の先に炎を配置。
- 正面を横圧縮した疑似斜めではなく、斜め・背面を別の絵として検討。

## 人間の目でのセルフレビュー：まだ不足しているところ
1. **方向ごとの一致**：斜めと背面の体型／尾の根本／腕の前後位置は、パーツ別の正確な共通骨格があるわけではない。現時点では矛盾が起きる恐れがある。
2. **表情差分**：口・瞳・眉毛の形を、原作のゲーム内バトル用の感情表現に合わせて検証する必要がある。
3. **2.5Dの本質**：絵が立体的に見えるだけで、現在は骨格も回転できるキャラモデルもない。完成と呼んではいけない。
4. **小画面**：80pxまで縮めた画像は、鈴と目の識別を優先する必要がある。細かい陰影がゲーム画面で意味を持つか検証する。
5. **アニメーション**：待機・パンチ・被弾などのキーポーズも、接地も未検証。G2→G3のゲートを飛ばさない。
6. **権利**：ジバニャンは原作に権利のあるキャラクター。自作の描画でも二次創作の利用には権利上の検討が必要。PublicのGitHubリポジトリは**ブランチも公開**されるので、現段階では画像・派生SVGをコミットせず、プライベートな成果物として保管する。
