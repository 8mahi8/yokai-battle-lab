## 素早さ→行動後の待ちポイント（研究説）

研究者の書いた整数部分の式をコードへ転記（独立検証済みではない）。

```text
s <= 171:           369 - floor(s/3) * 3
172 <= s <= 201:    198 - floor((s-171)/5) * 3
202 <= s <= 501:    180 - floor((s-201)/10) * 3
s >= 502:           90
```

実例：s=171→198、176→195、201→180、210→180、211→177、501→90。

## 今回の暫定スケジューラ（**原作の確定仕様ではない**）

1. 同一の6体編成×2チームを持つ。前衛はリング上で連続する3体。後衛は行動抽選に含まれない。
2. 前衛の初期待ち値は非公式の妖怪ウォッチ2用94行表に載る素早さ別の範囲から整数乱数で選択する（seed固定）。後衛はアクティブな待ち値を持たない（null）。
3. 行動イベント毎に、両チームの前衛6体から待ち値最小の1体を選び、その最小値を全前衛の待ち値から減らす。選ばれたキャラは行動後のポイントに戻す。
4. 回転時、前衛に残留するユニットの待ち値は保持。新たに前衛に入るユニットは 3×速度weight の待ち値へ再設定。後衛へ下がったユニットは待ち値を無効化。
5. 同値は現在のスロット左→中央→右、A→B順。これはテストのための決定的な**仮優先順**。
6. 回転制限の現実の経過ミリ秒は行動ポイントの進行とは別にする。**ATBリアルタイムゲージにはしない**。

注意：これは**行動順研究の道具**であって、現時点で原作行動順の一致率を検証できたものではない。原作映像の行動ログ・実機の同編成の観測データを照合するまで正式仕様へ昇格させない。
