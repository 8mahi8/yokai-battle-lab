## こちらで新たに試した復旧
- `container.exec` でファイル一覧やffmpeg/ffprobe環境を調べる最小コマンド → **ClientError**、標準出力なし。
- `python.exec` で`/mnt/data`の存在を確認する最小コード → **ClientError**。
- `python_user_visible.exec` でMP4ファイル一覧を見る最小コード → **ClientError**。
- `container.exec` で文字列をechoするだけの最小コマンドに絞って再確認 → **ClientError**。ffmpegのみの不具合ではなく**コンテナ・コード実行バックエンドの呼び出し自体に障害**がある可能性が高い。
- Files `list` でMP4の登録・MIME・サイズは確認できる。Files `read` のMP4は「No readable content was found」（音声テキストや映像フレームへの自動変換なし）。
- 独立した動画処理サービスの入力を調べたが、ユーザー提供ファイルの**ネイティブ添付バインディング／読める公開HTTPS URL**が必要。現状の文字列ファイルIDや`/mnt/data`パスだけを投げてはならず、本人に新しいプラグイン用アップロードUI操作を要求しない範囲では実行不能。
- 第1試合の以前作成済みコンタクトシート画像はFilesの`image_file`で**再度実画像として確認できる**。第2〜4試合については現在この種の画像生成物も無い。
