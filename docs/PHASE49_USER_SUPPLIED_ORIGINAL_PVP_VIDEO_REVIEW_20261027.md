## 証拠の出どころ
2026-10-27 本人が本チャットに添付したMP4 `ScreenRecording_10-27-2026 20-42-47_1.mp4` を**実際に読み取り・動画フレーム抽出して観察**。YouTubeへの自動アクセス・ログイン・cookie利用は不要になった。

`ffprobe` 計測：**216.533秒、1108×512、30fps、H.264映像/AAC音声、158,654,027 bytes**。4秒ごと全54サンプル、重要区間（00:24–00:48、01:00–01:24、02:00–02:24、02:45–03:12）を1秒刻みでサンプリングし、実画面の構成とアクションをレビューした。

**著作権対応**：添付された実況のフレームや動画そのものを公開GitHubへ転載しない。ここには本人のゲームを改善するための**文字の観察記録**のみ残す。重要な区別：画面下部の大きな赤・青・白字幕、吹き出し内の追加キャラ画像、一部の解説・ステータス図は**動画制作者の編集**。原作ゲームUIとして模倣しない。録画の戦闘間には編集/カットがある。録画全体で測ったアクション頻度=本家の内部クロックではない。

## 重要：今回の映像だけでは言えないこと
- 元の3DSプログラムにおける行動待ちポイントの内部処理、ダメージ計算式、サボり・スキルの正確な確率。
- **相手視点でのサークル表示保留**：今回の映像は試合の2視点を時刻同期させた比較ではない。ノーモーション必殺の因果は今回の動画だけでは直接検証できない。
- 画面内の色付き字幕のすべてが「ゲーム内UI」だという主張。大部分は動画制作者の編集。
- モーションの正式なミリ秒値。01:12-01:15等の見た目の持続は**編集済み動画上の概算**であり、原作ゲーム内で保証された再生時間ではない。

## 反映する開発判断
1. **必殺カットインの舞台全体を使った大型表示**。戦闘描画から切り替わる演出を`anticipation`、ヒット/HP変化を`impact`に割り当てる。既存のホスト確定ダメージは変えない。キャラごとにCSSに埋め込まずデータ/ローカルSVG再利用。
2. **ピン標的の円形照準**。現行の黄色▼だけでは弱い。ポインタが指に隠れても可読な円形リングを付け、対象キャラに常時付随する。
3. **良悪とりつき・ガード等は、キャラの近くで状態が見える**。HP/妖気の細いバーを邪魔せず表示。予備動作と命中後の区別は維持。
4. **スキルと攻撃は独立した表示**。Stage48のスキル発動通知はそのまま利用。字幕風の大きな実況キャプションはコピーしない。
5. ブラウザ版は3DSと同じ内部コードでなくてよい。Safari/Google Sites上で**戦闘体験と読み合いの一致**を優先。
6. 新しい変更をスクリーンショットQAで確認し、学校配布版・mainは勝手に更新しない。
