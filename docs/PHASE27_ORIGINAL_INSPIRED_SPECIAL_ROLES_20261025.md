# Phase27｜原作キャラの完全コピーではなく、必殺技の役割を参考にする（2026-10-25）

## 決定した基本方針
本人の希望：「キャラは完全再現しなくていいけど、必殺技の種類とかそういうキャラのものは参考にするといい」。
- **レンタル6体はオリジナルの名前・姿を維持**する。原作キャラの絵や固有名の再現は必須でない。
- 原作対人の奥深さにつながる**技の分類と役割**を参考にし、まず1試合が最初から終了まで成立することを優先。
- 詳細な威力・回復量・異常Lvなどは原作確定値ではなく**試遊用の仮値**。友達と遊んでから調整。閃光魂・育成・ランキング・リロード後の対戦復帰は対象外。

## 参考にした原作効果
- [攻略大百科・妖怪ウォッチ2必殺技一覧](https://gamepedia.jp/youkai-yw2/specials)：単体攻撃、全体攻撃、回復、おはらい、能力上昇など。
- [個別技・複合効果の例](https://gamepedia.jp/youkai-yw2/specials/3929)：攻撃＋継続ダメージ、全体弱体化、混乱など。
- [回復・復活・HP吸収の例](https://3dsnote.com/youkai2/hissatsu-ichiran/)：全体回復、気絶者復活、敵のHPを吸収して味方へ与える技。
- [原作YW2とりつきの効果・持続](https://mtwildwood.net/inspirits.php?g=yw2)：強化/弱体化/おはらい、持続ルール。

## 今回の実装と再利用
1. 既存の必殺研究関数 validateSpecialSpec / planResearchSpecial を拡張。攻撃/回復に加えて buff / debuff を処理。現時点は既に状態台帳にある強化・弱体化の種類に限定。
2. 通常の戦闘エンジンの必殺実行時に、既存 applyInspirit を利用。悪いとりつきの抵抗は既存のシード付き乱数で判定。戦闘中のホスト権威と再演条件を維持。未実測のLv・威力は仮値。
3. 新テスト6件追加。既存テスト522件＋6件＝528件のNodeテストに成功。研究用の状態台帳を作り直していない。
